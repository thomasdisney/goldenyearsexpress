# The Golden Years Express

One-page partnership site for **The Golden Years Express** — Rat Pack entertainment by rail for senior communities and veterans.

- **Domain:** [GoldenYearsExpress.org](https://www.goldenyearsexpress.org)
- **Umbrella:** [Rat Pack Events](https://www.ratpackevents.com) (`../deano`)
- **Full cast show site:** [Deanoholics.com](https://www.deanoholics.com) (`../deanoholics`)

## Develop

```bash
npm install
npm run dev
```

## Content

Copy lives in `src/data/content.ts`. Poster: `public/images/poster-golden-years-express.jpg`.

Donation buttons use direct Venmo / PayPal URLs (decoded from the Drive QR codes) — not QR images on the page.
